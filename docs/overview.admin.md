## What it does

Capell Inertia Vue Adapter supplies the Vue side of Inertia-powered themes.

## Do I need to do anything?

Usually no. It works behind the scenes once installed. You will see its effect only if you use a Vue-based Inertia theme.

## Where it shows up

In how a Vue Inertia theme renders; there is no separate screen to operate.

## Good to know

- Install this only if your Inertia theme uses Vue.
- It works alongside Capell Inertia; install that too.
